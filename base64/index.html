What is Base64?

Base64 is a binary-to-text encoding scheme that represents binary data using 64 ASCII characters (A-Z, a-z, 0-9, +, /). It's commonly used to encode data in emails (MIME), embed images in HTML/CSS (data URIs), store binary data in JSON, and transmit data over text-based protocols. One Base64 string that is not data: the digest in an integrity attribute — that one comes from the Hash Generator.
